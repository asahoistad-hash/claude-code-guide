Så fungerar Claude Code

Claude Code är en AI-assistent som arbetar direkt i din projektmapp: den läser filer, skriver kod och kör kommandon, och du styr det hela med vanlig text.

Så funkar det i fyra steg

  1. Du beskriver vad du villSkriv på vanlig svenska eller engelska, till exempel "gör en enkel hemsida om mitt projekt".
  2. Claude utforskar och planerarDen läser relevanta filer i mappen och bestämmer vilka steg som behövs.
  3. Claude gör ändringarnaDen skapar och redigerar filer och kör kommandon, till exempel tester eller git.
  4. Du granskar och styrDu godkänner eller nekar åtgärder och kan alltid be om ändringar.

Du behåller kontrollen

Claude Code frågar om lov innan den gör något känsligt, som att köra kommandon eller ändra filer. Du bestämmer hur mycket den får göra på egen hand.

Bra att känna till

CLAUDE.md är en fil där du skriver instruktioner som Claude läser varje gång, till exempel hur projektet är uppbyggt.

Skills och verktyg låter Claude göra mer, som att bläddra på webben eller ansluta till andra tjänster.

Git fungerar bra tillsammans med Claude Code: du kan spara varje steg och alltid backa.

Kom igång

Installera och starta i valfri projektmapp:

cd mitt-projekt
claude

Läs mer i den officiella dokumentationen.
